# Glossary

| Term | Meaning |
| --- | --- |
| Workspace | A set of repositories treated as one engineering context. |
| Contract | A human-readable behavior promise under a configured contract root, typically `docs/contracts/`. |
| Code anchor | A searchable source-level symbol such as a service, controller, client, exported function or config block. |
| Known gap | A stable ID for an open risk, missing behavior or validation item. |
| Retrieval regression test | A test query whose expected top result protects retrieval behavior from drift. |
| Manifest | Portable generated metadata in `.contractmesh/index/search-index.manifest.json`. |
| Local index | Machine-specific generated metadata in `.contractmesh/index/search-index.local.json`. |
| Source provenance | The documents, anchors, and chunks cited by retrieval so an answer can be audited. |
