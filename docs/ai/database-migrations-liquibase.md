# Database migration guidance

This file is a generic example of operational knowledge that can be indexed by
ContractMesh. Replace it with your team's actual migration rules.

Recommended contract for migration systems:

- Treat already-applied migrations as immutable.
- Add new migrations for schema corrections.
- Document compatibility expectations for rolling deploys.
- Link migration rules from affected service contracts.
- Add known gaps when migration behavior differs between environments.

The basic template does not depend on a specific migration tool.
